# ТЕТРИС · Neon Edition

Тетрис по современным правилам с неоновым интерфейсом и мультиплеером по WebSocket.
Без сборщика и без npm-зависимостей: браузер сам грузит нативные ES-модули,
React 18 (UMD) лежит рядом в `vendor/`.

## Что внутри

**Правила**
- SRS: четыре состояния поворота, пристенные сдвиги (свои таблицы для I), разворот на 180°.
- «Мешок семи»: каждая фигура выпадает раз за цикл.
- Удержание фигуры (`C`) и очередь следующих.
- T-спины по правилу трёх углов, мини-спины, back-to-back, комбо, идеальная зачистка.
- Задержка приземления с ограничением на 15 доводок, буфер спавна и проигрыш по lock out.
- Очки за софт- и хард-дроп, скорость падения по гайдлайну (до 20 уровня).

**Мультиплеер**
- Комнаты по коду (до 8 игроков), ники, чат, мини-доски соперников.
- Мусорные ряды: слом от 2 линий, спины и комбо шлют мусор соперникам,
  своя атака гасит входящую.

**Картинка и эффекты**
- Тема «неоновое стекло»: тёмная сцена, плывущие пятна света, сетка, которая
  теплеет с уровнем. Никакого космоса.
- Слом ряда — целая сцена: время почти останавливается, камера наезжает на
  обречённые ряды, стакан плывёт волной, ряды разлетаются, сходятся линии
  скорости, нарастает звук. В момент слома — стоп-кадр, вспышка, глитч,
  прокрутка оттенка по всему экрану, конфетти, молнии, ударные волны и салют.
- Фон реагирует на игру: чем длиннее комбо, выше уровень и ближе завал к верху,
  тем сильнее всё плывёт — сетка идёт волнами, включается тоннель из колец
  и калейдоскоп, экран медленно меняет оттенок.
- Хард-дроп, приземление, мусор, новый уровень и конец игры — каждый со своим
  набором тряски, стоп-кадров, разрывов картинки и частиц.
- Переключатель силы эффектов в шапке: `СПОКОЙНО` · `ЛЮТО` · `БЕЗУМИЕ`.
  Выбор запоминается.
- Кадр под присмотром: если машина не тянет, качество эффектов плавно
  снижается само (реже перерисовывается фон, меньше частиц, слабее размытие).
- Системная настройка «меньше движения» полностью выключает тряску, зумы,
  глитч и экранные фильтры.

**Звук**
- Синтезирован целиком на Web Audio: эффекты, нарастающий «риск» перед сломом
  и фоновая музыка, темп которой растёт вместе с уровнем.
- Управление с клавиатуры (DAS/ARR) и жестами на телефоне; макет адаптивный.

## Структура

| Путь | Назначение |
|---|---|
| `index.html` | Шелл страницы: стили, React UMD, точка входа |
| `css/` | Токены темы, каркас, компоненты, эффекты |
| `src/core/` | Правила без DOM: константы, фигуры и SRS, поле, очки, `Game` |
| `src/render/` | Палитра, отрисовка блоков, стакана, превью, соперников, фона, частицы |
| `src/fx/` | Экранные эффекты: замедление, стоп-кадры, зумы, глитч, тряска |
| `src/audio/` | Синтезатор звука и музыки |
| `src/net/` | WebSocket-клиент с переподключением |
| `src/input/` | Клавиатура с автоповтором и жесты |
| `src/app/session.js` | Связка правил, картинки, звука и сети + игровой цикл |
| `src/ui/` | React-интерфейс (`React.createElement`, без JSX) |
| `server.py` | WebSocket-бэкенд: комнаты, чат, состояние, атаки |
| `tests/` | Тесты правил и сетевого клиента |

Слои не знают друг о друге: `src/core` не трогает DOM, `src/render` не меняет
состояние игры, а `Session` связывает их через события.

## Запуск

```bash
# WebSocket-бэкенд :8283 (нужен пакет websockets)
python3 server.py

# статика :6767
python3 -m http.server 6767
```

Открыть `http://<host>:6767/`. Без бэкенда игра работает — не будет только
мультиплеера.

## Тесты

```bash
npm test          # или: node --test tests/*.test.mjs
```

47 проверок: мешок фигур, пристенные сдвиги, слом рядов, мусор, T-спины,
очки и атака, игровой цикл, снимок состояния, сетевой протокол, а также
поведение эффектов — замедление, стоп-кадры, пределы наезда камеры,
экранный фильтр и режим «меньше движения».

## Управление

| Действие | Клавиши |
|---|---|
| Движение | `←` `→` (или `A` / `D`) |
| Поворот | `↑` / `X` — по часовой, `Z` — против, `Q` — на 180° |
| Ускорить | `↓` |
| Сбросить | `Space` |
| Удержать | `C` / `Shift` |
| Пауза | `P` / `Esc` |
| Заново | `R` |
| Звук | `M` |
| Сила эффектов | кнопка в шапке |

На телефоне: свайп влево-вправо — движение, свайп вниз — ускорение,
резкий свайп вниз — сброс, свайп вверх — удержание, тап — поворот.
Плюс экранные кнопки под стаканом.

## Протокол WebSocket

Клиент → сервер: `create {nick}`, `join {nick, room}`, `leave`, `list`,
`chat {msg}`, `state {board, piece, gy, score, lines, level, combo, over}`,
`attack {lines}`.

Сервер → клиент: `joined {room, you}`, `err {msg}`, `rooms [{code, players}]`,
`room {code, players}`, `chat {nick, msg}`, `state {id, nick, …}`,
`attack {id, nick, lines}`.

Сервер не знает правил игры — он только раздаёт сообщения по комнате.
